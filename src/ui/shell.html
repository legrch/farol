    How to add this Farol in ChatGPT

    1. In ChatGPT, open Settings → Security and login → Developer mode. Then open Plugins using the link above.
    2. Select ＋, name the app your separate NEW app, and choose Connection → Tunnel. Select your tunnel and No authentication. Keep your runtime key in Farol, not in this form. Reuse an separate NEW app for the current tunnel instead of creating a duplicate.
    3. Return here and select Run end-to-end check. Farol opens ChatGPT, selects that app, and sends one short connection check. You can watch the reply, then return to Setup to see the result.
