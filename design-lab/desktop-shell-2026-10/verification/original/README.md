# Historical inspection scripts

Original scripts from the design session, retained as provenance only. They may
contain the original workstation paths and expect the original directory layout
or loopback server. Do not use these as the portable test entry point. Use the
package-root `verify.mjs`; it resolves dependencies from a caller-selected Farol
checkout and writes fresh results only under that checkout's ignored `_output`.
Original reports and screenshots in the package remain unchanged.
