One click to return to your work

Click the Farol symbol above. Status is brief; controls and task details live in the main application.

State is a shape, not a flashing color

Ready uses the plain mark. Running changes the center. Attention uses an exclamation; disconnected uses a cross. An available update uses a download arrow. The tooltip and open menu explain each state in words.

Keep this menu small

Status, Open Farol, Check for Updates… and Quit Farol. A running-task count or attention reason can open the relevant screen. No folder permissions, model selectors or second Settings interface.

Show a menu-bar icon can be an option in General. The native implementation should use one shared command router for menu items and the main app, and respect the existing quit/update gates.
