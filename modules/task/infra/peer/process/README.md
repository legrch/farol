# Task consumer of selected Computer process

New accepts one actual published `computer/contracts/process.Contract` and exact
immutable operation/runtime/session/model/admission correlation from trusted
composition. Only public neighbor contracts are imported. Task cannot supply
executable, environment/HOME, roots, lease/deadline, a process factory or authority.

Prepare forwards copied bounded arguments/stdin to the same selected contract;
the response must match every correlation and command digest shape. It is not
admission, native launch or observed provider identity. Input stays transient;
only a local content fingerprint and correlation receipt are retained here.
Prepare/Start/Cancel are each attempted at most once by this peer. Known local
receipt replay does not invoke the boundary again. Changed payload conflicts;
refused/unknown/malformed/panicking boundaries remain binding. Local fences are
additional protection, not durable ownership or permission to reconstruct an
operation after restart. The existing Task and Computer journal owners retain
that policy; no new executor or recovery database is introduced.

Read uses the retained exact handle and offsets. Base64/byte limits and next
offsets must agree; responses cannot substitute another child or range. Terminal
mapping requires root Wait, drained output, and both confirmed cleanup facts.
Unverified cohort cleanup maps to unknown even with clean root exit. Decoded
bytes/exit code are independent copies. Cancel request ACK remains separate from
terminal settlement and a refused/unknown signal is never repeated or escalated.
Read/reconnect cannot prepare or start another invocation. Typed failures preserve
classified outcome/refused versus unknown and Retry=never without raw diagnostics.

Source tests inject public-contract DTO scripts; production constructor accepts
only the concrete published contract. Real selected root binding, current CLI
capability/entitlement, effective confinement, cohort/parent-death supervision,
durable reservation/result/reconnect routing and native qualification remain
Lead/Computer-owned. This peer advertises no Claude provider capability and does
not widen the selected lease's original ordinary <=15s deadline.
