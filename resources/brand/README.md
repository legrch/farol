# Farol brand assets

The current raster/Dock/package source is [Sunrise](sunrise/README.md), selected
as the owner's current direction on October 6, 2026. `tooling/brand-contract.mjs`
maps its exact source-local master to both raster output names and its ICNS to
the existing package resource name. Light and dark use identical artwork.
Native/package acceptance is separate from the offline resource checks.

The following lamp provenance and the [Signal / Color](signal-color/README.md)
record describe historical resources. They remain preserved; their original
approval records and frozen packages are not changed by the Sunrise mapping.

## Historical lamp resources

The owner authorized reuse of the existing Farol lamp mark for the product
cutover on October 1, 2026. These are source-local assets; building Farol does
not read a legacy checkout or installed application.

`farol-source.svg` is the unchanged multi-artboard master originally owned by
the Farol project, SHA-256
`bcbb69af0d64809d399c4704092c3ac500ca451762ac9cdeb3d016ebbad62fa4`.
`farol.icns` is the unchanged production icon, SHA-256
`61722544638e8d017969b9c88edb69a0f4dcd6763e31d1e9f8122835e9b2e2d6`.
The approved source snapshot was `7ccca1b7f34ca99bac849d27bca8e8278c3ebe79`.

`scripts/make-brand-assets.py` extracts the app artboard as `farol-mark.svg`
and derives `farol-dev-mark.svg` with a legible DEV badge. Each mark has a PNG
for Electron's Dock image API. Regeneration uses the existing `rsvg-convert`.
Committed assets require no renderer during build or packaging. No runtime
profile access is needed. Production ICNS bytes are never regenerated by it.

The app artboard is rendered alone, rather than shrinking the complete sheet.
Build and package admission verify the selected source-local bytes.
