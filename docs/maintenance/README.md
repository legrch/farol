# Older preview maintenance

This section applies to installations using the older `Farol Next Preview.app`
layout. It is separate from ordinary [installation](../start/installation.md),
[updates](../guides/updates.md), and source development.

- [Closed preview migration and recovery](preview-cutover.md) — applicability,
  exact identity/evidence parameters, closed-app obligations, custody, and known
  concurrent-startup limits.

Start from that procedure's prerequisites. Preserve the original evidence and
closed-app window; a new basename or a relaunch request is not a completed migration.
