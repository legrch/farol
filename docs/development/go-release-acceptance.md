## First source packet and retained boundaries

The highest-priority next source packet is **slot-proof completion before helper selection** (A–C). Proposed exact owned files are `modules/release/infra/native/slotbinding/verify.go`, `modules/release/infra/native/slotbinding/verify_test.go`, `modules/release/infra/native/helperprotocol/slotbinding_test.go`, a new `modules/release/infra/native/helperprotocol/testdata/slot-binding-golden.json`, `modules/release/app/services/helperprotocol/slotbinding_test.go` and `docs/reference/modules/release/slot-binding.md`; keep production codec/input changes out unless an independently demonstrated parity defect requires a revised packet. Reuse the merged helperlocks tests as a dependency. Acceptance is independent original-producer vectors, explicit proof capability documentation, preserved privacy and descriptor state, deadline/native-return custody witnesses, V1/V2 and documentation checks, plus independent exact-range review. It does not select a helper or retire Python. Journal extension follows as a separately assigned writer; protected boot/launcher/runtime changes require their owners' packets.

- Preserve `farol.installed-operation-slot/1`, `farol.installed-update-journal/1`, all 13 existing helper phases, current restore/retained/download/receipt schemas, accepted build/profile identity and bundle/state/partition compatibility. A CAS revision, directory identity, verified tree or lock is evidence within the existing authority, never a new permission source.
- Keep the one authoritative Release operation, shared serialization/exclusion, immutable slots, exact expected source/target pair and original deadline. Do not create another journal, transaction engine, lock domain, fallback updater or automatic recovery loop.
- UNKNOWN remains retained across cancellation, Close, visible bytes, late ACK, re-observation, new handles and caller restart. Never replay a historical dispatch/launch, renew a hop budget or treat timeout/kill requests as actual native return. Reconciliation requires the existing owner and real original-writer/helper quiescence; explicit recovery is a separately admitted effect.
- Escalate unresolved compatibility, authority, deadline propagation or cross-owner contracts to the integration Lead before implementation. Preserve unsupported native cases and skipped/failed/unknown evidence explicitly; no predicate, permission, pin or verification weakening is a completion path.
- Production app/profile, credentials, signing, installation, publication and external effects remain outside these source packets. Keep native disposable state and package/installed/live/owner acceptance distinct. Public documentation references repository sources only; private notes and incident evidence stay outside this artifact.
