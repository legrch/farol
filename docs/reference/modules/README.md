# Go module documentation

Canonical module specifications live here; executable Go packages remain under
`modules/`. Each module index retains its contracts, historical source pins and
acceptance limits.

- [Computer](computer/README.md): access, admission, files and process execution.
- [Chat](chat/README.md): turns, lifecycle, browser exchange and retained results.
- [Task](task/README.md): coding-task control, selected reads and workflow adapters.
- [Release](release/README.md): update, journal, adoption and native boundaries.

Read [AGENTS.md](../../../AGENTS.md) for current ownership and checkpoint policy.
Go source presence does not establish runtime activation, native qualification,
packaging, installation or live-provider acceptance. Historical proposals retain
their own stated limits.
