# Computer reference

Computer owns access to approved physical workspace roots and the task-scoped
operations performed through them.

- [Capabilities and limits](capabilities.md) — reads, mutations, Git/shell modes,
  intent/effect evidence, exclusions, and process cleanup.
- [Workspace context](workspace-context.md) — workspace IDs, applicable `AGENTS.md`,
  published guidance, and bounded coverage.

To perform an access change, use [folder access](../../guides/folder-access.md).
For the design, read [authority](../../architecture/authority.md). The additive Go
read adapter has its separate [Desktop/Core contract](../protocols/desktop-core.md).
