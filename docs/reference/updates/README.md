# Update contracts

Read the contracts in their verification and effect order. For the ordinary action,
use [Update Farol](../../guides/updates.md).

1. [GitHub release contract](release.md) — feed, channels, manifests, assets,
   bounded discovery, and transport.
2. [Package verifier](verifier.md) — archive limits, extracted identity, ASAR,
   and owned verification resources.
3. [Installed updater](runtime.md) — baseline, staging, admission, drain,
   helper handoff, restart, and recovery.
4. [Installed helper](helper.md) — exact acknowledgment, atomic replacement,
   journal evidence, helper lifetime, and pair reconciliation.

Older slot retirement and recovery belong to
[closed preview maintenance](../../maintenance/preview-cutover.md). Release
publication, source checks, installed acceptance, and account reconnection remain
separate evidence in [current status](../status.md).

For the named beta metadata and its verification limits, see
[published release evidence](evidence/README.md).
