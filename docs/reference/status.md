Native assessment of a disposable extracted copy found no usable code signature. No Gatekeeper override or quarantine removal was used. The exact Finder warning/Move to Trash sequence was not reproduced.

Current source derives the advertised **macOS 13.0** floor from authenticated Electron 44.4.2 metadata; the separate source package agrees. The installed internal package still advertises 12.0 in its outer plist, while its bundled Electron requires 13.0. Neither declaration proves support on every Mac at that version. A clean-machine support and prerequisite matrix remains open; Intel, Windows and Linux are not qualified.

Electron/Node and the Go backend are packaged. In Go-aware builds the installed update helpers, slot/handoff binding, Computer file operations and Settings search run through the Go backend with no Python fallback; `safe_open.py` stays packaged for the readonly workspace and explicit legacy/dev paths, and `update_helper.py` stays packaged, undispatched, under the [bridge rule](../installed-update-helper.md#retiring-the-python-helper-bridge-rule) ([runtime dependencies](../development/runtime-dependencies.md)). This is source selection, not installed acceptance. Ordinary Git qualification is tied to selected native resources. TypeScript agent orchestration and Release policy also remain active; the existence of Go modules does not prove those routes have switched.
