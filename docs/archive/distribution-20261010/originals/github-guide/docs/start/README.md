# Start using Farol

Complete one small read-only session before enabling broader access. This path
introduces the app, its connection to ChatGPT, and a workspace you can inspect.

## Your first session

1. [Install and open Farol](installation.md). Check platform requirements and the
   beta's signing and installation limits.
2. [Connect ChatGPT](first-connection.md). Select a folder and verify the exact
   attached app.
3. [Read your first workspace](first-workspace.md). Use a small folder you created
   for the exercise and confirm the answer against its file.

The result is a checked connection and a read-only workspace. Editing, shell
commands, full Git, and native task delegation have separate access requirements.

Already connected? Go directly to [practical guides](../guides/README.md).
Want to run a development build? Start with [development setup](../development/setup.md).
