to recognize the result.

| --------------------------------------------------------------- | ---------------------------------------- |
| Approve a folder or change its permissions                      | [Change folder access](folder-access.md) |
| Apply an update or restore an accepted version                  | [Update Farol](updates.md)               |
| Resolve a connection, access, configuration, or startup problem | [Troubleshoot Farol](troubleshooting.md) |
