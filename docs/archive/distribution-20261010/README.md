# Frozen distribution and documentation material — 2026-10-10

This is a **nonshipping historical archive**, not current product documentation,
a runnable tool suite, an installer, an OTA producer, or accepted verification policy.
The owner selected preservation while prioritizing the separately assigned current
OTA archive adaptation. Current repository instructions and owning contracts govern.

[manifest.json](manifest.json) records all four exact commit/tree pins, per-file
original paths and Git blob IDs, SHA-256, byte lengths, decisions and limits.
Copies retain original bytes beneath `originals/<branch>/` and preserve the original
path hierarchy. Executable sources gain `.txt` (`.mjs.txt`, `.sh.txt`, `.py.txt`)
and all copied files have mode `0644`. They must never be executed or imported.
