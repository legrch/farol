# Farol 0.5.31 release notes (draft)

## Updating

- **0.5.29 users** update normally, from Settings, General, Check for updates.
- **0.5.30 was withdrawn.** Every installed 0.5.29 refused it. If you installed
  0.5.30 by hand, install 0.5.31 by hand too: its updater cannot be relied on to
  reach this release.

## Behaviour change

- Workspace folders that group or other users can write to are refused again, as
  in 0.5.29. 0.5.30 had briefly allowed them. They stay refused until a later
  release, because 0.5.31 keeps the native helper identical to 0.5.29's so that
  0.5.29 installations can verify the update. Settings can still approve such a
  folder, because the Go settings route accepts and marks it, but the file tools
  then refuse it on every read, list, write and edit. Choose a folder that only
  your user can write to.

## Known limits

- Mutation history is limited to 4,096 files and 64 MiB.
- A turn admits at most 256 participants.
- Per-lifetime caps on operations still apply; a long-running session that
  reaches one needs a restart.
