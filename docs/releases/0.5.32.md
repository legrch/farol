# Farol 0.5.32

- **Ping works with ChatGPT's new Temporary chat layout.** Ping no longer refuses when ChatGPT changes its optional controls. It tries to open a Temporary chat, select Instant and set personalization, then types and sends in all cases. The result shows what happened at each step, for example "Sent · temporary: yes · model: Instant · personalization: unavailable".
- Ping never clears text you typed. If your draft is still in the composer, Ping does not send and tells you so.
- Ping is a best-effort check: a double click may send it twice.
- Updating works from 0.5.29 and 0.5.31. If you installed 0.5.30 by hand, install this version by hand too.
